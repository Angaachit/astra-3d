# Astra 3D Demo\n\nInteractive demo of the Astra 3D library with GPT-6 Astra AI integration.\n\n## Features\n\n- **Real-time 3D Rendering**: Interactive 3D visualization\n- **Performance Metrics**: Live FPS and triangle count display\n- **Interactive Controls**: Create and manipulate 3D objects\n- **Responsive Design**: Works on all screen sizes\n\n## Usage\n\nOpen `index.html` in a web browser to see the interactive demo.\n\n### Available Controls\n\n- **Create Cube**: Adds a new cube to the scene\n- **Create Sphere**: Adds a new sphere to the scene\n- **Create Pyramid**: Adds a new pyramid to the scene\n- **Rotate Scene**: Enables scene rotation animation\n- **Clear Scene**: Removes all objects from the scene\n\n## Technologies\n\n- HTML5 Canvas 2D Context\n- Vanilla JavaScript\n- CSS3 Grid & Flexbox\n- Responsive Design\n\n## Performance\n\nThe demo maintains 60 FPS on most modern browsers and displays:\n- Frame rate (FPS)\n- Number of mesh objects\n- Total triangle count\n\n## Deployment\n\nThis demo is deployed on GitHub Pages at:\n`https://Angaachit.github.io/astra-3d/`\n"
